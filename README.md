# Почтелье v3

Серверная версия конструктора HTML-писем и рассылок для платформы **skript.rt.ru** (Python Platform, OKD).

> Предыдущая версия (v2.x, десктопное приложение Flask + PyQt) живёт в отдельном репозитории
> `shablon_rassilok` и здесь не развивается. Из неё переносится только нужная логика.

## Цели

1. Визуал в стиле приложений РТК на `@universityrt/ui-kit`.
2. Современный стек: FastAPI + React/TypeScript.
3. Роли и права: что пользователь видит и может делать.
4. Хранение данных и учёт отправок.
5. Отправка и отложка без открытого приложения, учёт «отправлено или нет».
6. Интернационализация, задел под будущий почтовый клиент.

## Статус

Фаза 0: решения и каркас. Кода приложения пока нет. Решения и ограничения: [docs/adr/](docs/adr/).

## Структура (план)

```
backend/    FastAPI, SQLAlchemy 2, Alembic, structlog
frontend/   Vite + React + TypeScript + @universityrt/ui-kit
docs/adr/   архитектурные решения
```
