# ADR-0003: Редактор писем v2 во встроенном iframe, перенос на React по блокам

- **Статус:** Accepted
- **Дата:** 2026-10-21

## Контекст

Холст-редактор v2 — около 15 тысяч строк vanilla JS (холст, блоки, генерация HTML письма),
рассчитанных на Flask-эндпоинты. Переписать его целиком на React до первого результата
нельзя; ADR-0002 предполагал подключение «как есть».

В v2 два режима: пользовательский (открыть готовый шаблон, заполнить, сохранить личную
копию) и административный (конструктор: создание шаблонов с нуля).

## Решение

Гибрид: сначала встроить редактор через iframe, затем переносить блок за блоком на React и
UI Kit.

1. Файлы v2 скопированы в `frontend/public/editor/`: `index.html` (письма) и `admin.html`
   (конструктор). Правок кода редактора нет, кроме подключения `bridge.js` первым скриптом.
2. `bridge.js` перехватывает `fetch` в iframe и переводит вызовы v2 в API v3:
   шаблоны — в `/api/templates` (envelope, scope вместо type, uuid вместо `tpl_*`);
   конфиг и профиль — в `/api/editor/*`; heartbeat, jslog, mode — локальные заглушки;
   отправка, учётные данные, массовая рассылка, ресурсы пользователя — ответ 501
   «Недоступно в этой версии» (будут перенесены отдельно).
3. Каталог ресурсов (`config.json`, `icons/`, `images/`, …, ~40 МБ) не хранится в git:
   путь задаёт `RESOURCES_DIR`; бэкенд раздаёт категории от корня сайта (редактор строит
   URL как `origin + src`) и отфильтровывает записи каталога без файла.
4. Права: конструктор виден только роли `admin`; это лишь удобство интерфейса, запрет
   создания общих шаблонов обеспечивает API.
5. Функции отправки скрыты флагами `features` (`bulk_mail`, `exchange_send` = false).

## Последствия

- Быстрый рабочий результат без переписывания; один домен, поэтому iframe не требует CORS.
- В проекте остаётся vanilla JS до завершения переноса; удалять `bridge.js` по мере
  переноса блоков.
- Категории шаблонов выводятся из самих шаблонов, пустые категории хранятся только в
  localStorage браузера.
- Миграция существующих шаблонов v2 (JSON-файлы) в v3 не реализована.
- Каталог ресурсов в проде должен приходить из хранилища платформы (S3 или файловое API):
  открытый вопрос в ADR-0001.

## Проверено

Через Playwright (Edge): открытие общего шаблона с баннером и картинками, сохранение
личной копии, создание общего шаблона в конструкторе с миниатюрой и его появление в
редакторе писем.
